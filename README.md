# ZOO-TRAINING

Учебный сайт о мастер-классах по дрессировке в зоопарке-заповеднике будущего. В 2038 году климатические технологии позволяют собрать на одной территории три мира — **Сафари**, **Джунгли** и **Вечную мерзлоту**, а лучшие дрессировщики проводят мастер-классы в каждом из них.

**Автор:** Кузьменко Михаил, НИУ ВШЭ, группа БРИЦП 262

## Как открыть

Скачайте репозиторий и откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

## Структура

```
index.html        — главная страница
404.html          — страница-заглушка «404»
css/reset.css     — сброс стилей
css/style.css     — стили главной
css/404.css       — стили страницы 404
assets/           — логотип, иллюстрации (SVG), фотографии
```

## Технологии

- HTML5 и CSS3 без фреймворков
- Шрифт Inter (Google Fonts)
- Адаптивная вёрстка: `clamp()`, `aspect-ratio`, медиазапросы

## Использование ИИ

При работе над сайтом я использовал ассистента **Claude** (Anthropic). Вот с чем он помогал:

### Страница 404
Страницу 404 Claude сделал полностью: `404.html` и `css/404.css`. На ней фоновая картинка на весь экран с затемнением, крупная надпись «404» и одна кнопка «Вернуться на сайт», которая ведёт на главную. Ещё он перенаправил на эту страницу все кнопки-заглушки: «Записаться», карточки биомов и товары магазина.

### Шапка сайта
Claude помог со всем, что касается шапки:
- шапка закреплена сверху (`position: fixed`) и остаётся на месте при прокрутке;
- полупрозрачный «стеклянный» фон с размытием (`backdrop-filter`);
- плавная прокрутка к разделам при клике на пункты меню (`scroll-behavior: smooth`).

### SVG-иллюстрации и адаптив
Claude помог настроить SVG-иллюстрации (деревья, животные, трава, корни, камни) так, чтобы при изменении размера и соотношения сторон окна они не ломались и не искажались. Для этого использованы `aspect-ratio` с пропорциями самих SVG и размеры в процентах.

### Помощь по вёрстке
Claude объяснил несколько моментов, которые были мне непонятны, и помог их исправить. Например:
- **Фото в магазине:** чтобы картинки товаров заполняли карточку и не сплющивались, используется `object-fit: cover`.
- **Пути к файлам с пробелами:** в названиях вроде `Tree 1.svg` пробел в ссылке надо писать как `%20`, иначе картинка не подгружается.
- **Незакрытый тег:** в подвале нашёлся лишний незакрытый `div`, из-за которого съезжала вёрстка. Claude его нашёл, и тег убрали.
- **Кликабельные контакты:** телефон сделан ссылкой `tel:`, Telegram и GitHub открываются по клику в новой вкладке.
